# Lo minimo para correr tools/traer_oece.py en una maquina peruana.
#
# POR QUE NO SE USA requirements.txt
#
#   El puente no levanta la web, ni los bots, ni genera documentos: solo pide
#   JSON a OECE y escribe en Supabase. Instalar las 26 dependencias del
#   proyecto en una PC de casa trae dos problemas gratis: psycopg2-binary no
#   compila en Python 3.13 -- lo necesita Alembic, que aqui no corre -- y
#   reportlab, lxml y python-docx tardan y no se usan.
#
#   asyncpg 0.31.0 y no 0.30.0 por una razon concreta: la 0.30 no publica
#   binario para Python 3.14, asi que pip intenta COMPILARLA y muere pidiendo
#   Microsoft Visual C++ 14.0. La 0.31 trae binarios de 3.11 a 3.14. Se subio
#   tambien en requirements.txt para que servidor y puente no divergan.
#
#   Estas estan fijadas a las mismas versiones que corre el servidor, para que
#   el puente y el bot ejecuten el MISMO codigo con las mismas librerias. Si
#   divergen, un fallo que solo pasa en uno de los dos cuesta el triple de
#   encontrar.
#
# POR QUE AHORA TAMBIEN HAY BeautifulSoup, Y POR QUE NO HAY lxml
#
#   El puente dejo de traer solo JSON: tambien cosecha el portal de
#   cotizaciones de Madre de Dios, que es HTML y que tampoco responde al VPS.
#   Sin BeautifulSoup, `tools/traer_oece.py` revienta al importar -- y
#   reventaria DESPUES de haber guardado OECE, que es la parte critica, con lo
#   cual el fallo pareceria peor de lo que es.
#
#   lxml NO se instala aqui, y es deliberado. El servidor si lo usa, pero esta
#   maquina corre Python 3.14 y lxml no publica binario para cada version nueva
#   enseguida: cuando falta, pip intenta COMPILARLO y muere pidiendo Microsoft
#   Visual C++ 14.0 -- exactamente el problema que ya obligo a subir asyncpg a
#   la 0.31. El orquestador cae al parser de la biblioteca estandar cuando lxml
#   no esta, y sobre el portal de Madre de Dios los dos sacan las mismas 25
#   filas.
#
#   Quien ya tenga el puente instalado necesita volver a correr:
#     .venv-tarea\Scripts\pip.exe install -r requirements-puente.txt
asyncpg==0.31.0
httpx==0.28.1
